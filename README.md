# Mayur Medicare Centre — मयूर मेडिकेयर सेंटर

Single-page website for Mayur Medicare Centre in Plaza Complex, Pratap Nagar, Mayur Vihar-1, Delhi.

One warm, mobile-first local clinic page with the essentials up front: Dr. Poonam Sachdeva, MBBS, DHA, CBA (Sono), landmark directions (behind Jeevan Anmol Hospital, opposite Bittu Tikki), consultation days and timings, day-based fees, services, call/WhatsApp actions, map access, and copyable phone/address details. Real storefront and interior photos help visitors recognize the clinic on arrival. Static HTML/CSS/JS, no backend.

Doctor availability, consultation timings, and services can change, so visitors should confirm directly with the clinic before visiting.
